# Third-party components

The CLI and independent desktop preview distribute the following components. Their upstream license and copyright notices remain applicable.

| Component | Version | Upstream |
|---|---|---|
| .NET runtime | CLI: .NET 10; desktop: self-contained .NET 8, resolved by the pinned SDK | https://github.com/dotnet/runtime |
| Godot Engine / GodotSharp | 4.7.2 stable, MIT and bundled third-party notices | https://godotengine.org/license/ |
| YamlDotNet | 18.1.0 | https://github.com/aaubry/YamlDotNet |
| AssetsTools.NET | 3.0.5 | https://github.com/nesrak1/AssetsTools.NET |
| three.js | 0.180.0 / r180, MIT | https://github.com/mrdoob/three.js |
| fflate | 0.8.2, MIT, fixed copy shipped upstream with three.js r180 | https://github.com/101arrowz/fflate |

Microsoft.NET.Test.Sdk, xUnit and the Visual Studio xUnit runner are development dependencies and are not included in the CLI publish output.

Godot is included in the desktop build. Its license and complete copyright notices are in `licenses/Godot-LICENSE.txt` and `licenses/Godot-COPYRIGHT.txt`. The engine's FBX/glTF decoder is used for source-model preview only; it does not establish Unity import/fileID compatibility. Assimp, Recast/Detour, xatlas, Embree and Open Image Denoise remain future integrations.

No source-project Shader, texture, model, plugin, private package URL, or Unity Editor binary is included in either application publish output. The desktop demo is newly authored native-format test content; its Unity loading remains separately unverified. System fonts are used from Windows and are not redistributed.

The local web development UI is served from source; no new application package is produced. Its fixed three.js modules, FBX/TGA loaders and decoder dependencies are local files under `src/SceneWorkbench.Web/wwwroot/vendor`, with `LICENSE` and `fflate-LICENSE.txt` alongside them. `vendor-manifest.json` records the official commit, original hashes and served hashes. Control/loader/curve imports use local relative modules. FBXLoader also copies six source-axis metadata values to `sceneGraph.userData.sourceAxes`; geometry algorithms remain upstream. Source texture references are resolved from Unity materials rather than external FBX URLs. No CDN is contacted by the running UI. Godot is not a dependency of the web service.

The source-only tests include the unchanged `BlitToRTHandle.unity` sample from Unity's URP 14.0.9 package. Its provenance and SHA-256 are in `tests/SceneWorkbench.Tests/Fixtures/Unity2022.3/provenance.json`; the original Unity Companion License is retained alongside it as `Unity-Package-LICENSE.md`. This fixture verifies observed YAML fields only and was not generated by launching Unity during development. No new application package is produced.

The EXRLoader is from the same pinned three.js r180 commit. Only its `three` import is adapted to the local module. Its OpenEXR / Industrial Light & Magic and TinyEXR / Syoyo Fujita copyright, redistribution conditions and disclaimers remain in `wwwroot/vendor/loaders/EXRLoader.js`. Raw and served hashes plus the upstream Git blob identity are in `vendor-manifest.json`. It decodes the user's existing project EXR for read-only preview; no source-project reflection image or lighting asset is added to application source or an application package.
